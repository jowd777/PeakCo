Design a modern e-commerce website UI for a premium streetwear headwear brand called Peak Co.. The brand focuses on high-quality urban caps inspired by 90s hip-hop culture, street art, DJs, dancers, and urban creators. The website should feel premium, bold, and street-inspired, while still maintaining a clean and professional online shopping experience.

Brand Concept

Peak Co. represents the “Peak Mindset”, meaning the drive to reach the top in music, dance, street culture, and creative industries. The brand sells premium headwear designed with durability and strong structure, combining classic hip-hop style with modern materials.

Products Sold

The store focuses on three core headwear products:

• High Crown 6-Panel Snapback
• 5-Panel Camper Cap
• Vintage Dad Hat

These products should be displayed with large high-quality images, price tags, and quick purchase options.

Design Style

Create a streetwear-inspired design that is:

• Bold and modern
• Influenced by hip-hop culture
• Minimal but premium
• Clean product-focused layout

Color palette suggestions:

• Black
• Charcoal gray
• White
• Silver
• Accent color: red or neon highlight

Typography should feel urban and bold, similar to modern streetwear brands.

Pages to Design
1. Home Page

Include:

• Large hero section with a cap product image
• Brand slogan: “Reach Your Peak.”
• Featured product section
• Limited drop collection section
• Brand story section about hip-hop culture inspiration
• Community section highlighting artist collaborations
• Newsletter signup

The layout should emphasize visual storytelling and product branding.

2. Shop Page

Create a product browsing interface.

Include:

• Product grid layout
• Filters for categories:

Snapbacks

Camper Caps

Dad Hats

Each product card should include:

• Product image
• Product name
• Price
• Add to cart button

3. Product Details Page

Display detailed information about a selected cap.

Include:

• Large product images
• Product description
• Price
• Available stock
• Add to cart button
• Product durability information

Highlight reinforced crown structure and shape-memory brim durability.

4. Cart Page

Include:

• List of selected items
• Product image preview
• Quantity adjustment buttons
• Remove item option
• Total price calculation
• Checkout button

5. Checkout Page

Include:

• Shipping information form
• Payment method selection
• Order summary
• Payment button

This page should be simple, secure, and easy to use.

6. Authentication Pages

Create UI for:

• User registration
• Login page

Include:

• Email and password fields
• Clean form layout
• Secure login design

7. Admin Dashboard (Optional UI)

Design a simple admin panel for store management.

Include:

• Product management table
• Order monitoring dashboard
• Sales overview section
• Buttons for adding, editing, and deleting products

UI/UX Requirements

Apply modern e-commerce best practices:

✔ Responsive layout for desktop and mobile
✔ Clear navigation bar
✔ Sticky header
✔ Search bar for products
✔ Shopping cart icon with item count
✔ Clean and structured product grid
✔ Easy checkout flow

Additional Visual Elements

Add elements that reinforce streetwear culture:

• Graffiti-inspired accents
• Urban textures or minimal background graphics
• Bold product photography
• Limited drop badges

The final design should feel like a premium streetwear brand website similar to modern hip-hop fashion stores, but unique to Peak Co..
